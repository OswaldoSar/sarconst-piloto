SARCONST INGENIEROS - PILOTO WEB PARA GITHUB PAGES
==================================================

Archivos incluidos:
- index.html
- assets/css/styles.css
- assets/js/script.js
- assets/img/ (logo e imágenes del piloto)

FUNCIONES DEL PILOTO
--------------------
1. Diseño responsive para celular, tablet y computadora.
2. Menú superior fijo y menú móvil.
3. Slider principal automático de 3 pantallas, con flechas, puntos y gesto táctil.
4. Sección de servicios con accesos a cotización.
5. Bloque interactivo para fisuras, ampliaciones, precompra y entrega de departamento.
6. Proceso de trabajo.
7. Galería horizontal con lightbox para ampliar imágenes.
8. Sección de presentación de SARCONST e Ing. Manuel Sardon Morveli.
9. Preguntas frecuentes tipo acordeón.
10. Formulario de contacto que genera un mensaje de WhatsApp.
11. Cotizador / solicitud de evaluación en 3 pasos.
12. Botón flotante de WhatsApp.
13. Animaciones de aparición, barra de progreso de lectura y botón para volver arriba.
14. SEO básico, Open Graph y datos estructurados.

PUBLICAR TEMPORALMENTE CON EL USUARIO ANTIGUO
---------------------------------------------
1. Ingresa a GitHub con tu usuario oswaldosar.
2. Crea un repositorio público llamado: sarconst-piloto
3. Sube TODO el contenido de esta carpeta conservando la estructura de carpetas.
4. En el repositorio entra a Settings > Pages.
5. En Build and deployment selecciona: Deploy from a branch.
6. Branch: main / (root) y presiona Save.
7. Espera unos minutos.
8. La dirección esperada será:
   https://oswaldosar.github.io/sarconst-piloto/
